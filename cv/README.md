# CV source

`cv.html` is the source of `public/cv.pdf`. Edit it, then print to PDF:

- Chrome: open `cv.html`, Print → Save as PDF, A4, margins None, background graphics on.
- The site version has no photo: add `class="no-photo"` to `<body>` before printing.
  Without it you get the version with the photo for local applications.

Fonts come from `app/fonts` and `public/fonts`, the photo is `photo.jpg`.
